# Gemini Chatbot 🤖

A Python-based AI chatbot powered by Google Gemini API. 
The chatbot provides conversational responses and maintains conversation memory.

## 🚀 Features

- Google Gemini API integration
- Conversational chatbot
- Chat memory
- Python-based backend
- Simple user interface
- Environment variables for API key security

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Streamlit
- python-dotenv
